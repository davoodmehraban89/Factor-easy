# WP1 — دفتر مالی سمت سرور

وضعیت: **در حال انجام؛ قابل انتشار نیست.**

هدف: رد سند نامتوازن و تغییر پس از قطعی‌شدن در خود پایگاه‌داده، با مسیر RPC تراکنشی، کنترل شرکت/سال/دسترسی، برگشت و شماره‌گذاری ایمن. شروع از WP0 PR194 با Quality41416988716/Security41416988731 موفق؛ گزارش خط مبنا و شواهد تحویل شده‌اند. PR194 هنوز ادغام نشده است؛ این شاخه روی آن قرار دارد.

کار جاری: انتقال انتخابی۱۱ SQL مرحله‌بندی‌شده از PR162–173 به شاخه مستقل، آزمون مجدد روی PostgreSQL17 برگرفته از migrationهای واقعی مخزن. هیچ API یا کد کلاینت فعال نشده و هیچ migration روی Production اجرا نشده است.

شواهد اولیه: تست مستقل D1/D2/D2_DIMENSION روی baseline با پیام مشخص WP1_REQUIRED_GUARDS_MISSING شکست خورد؛ روی زنجیره SQL منتقل‌شده موفق شد. D2 از سند جداگانه متوازن استفاده می‌کند؛ SET CONSTRAINTS ALL IMMEDIATE و فهرست خطاهای قابل‌قبول از قبولی کاذب جلوگیری می‌کنند. این قبولی، کل WP1 یا امنیت تمام RPCها را تأیید نمی‌کند.

یافته‌های باز در کد قبلی: حالت پیش‌فرض off؛ تغییر حالت توسط مالک عادی سازمان؛ نبود WHEN محدود به دفتر؛ شماره‌گذاری بدون تفکیک شرکت؛ کنترل ناکامل سال/ارز ردیف و وضعیت بسته سال مالی؛ مجوز برگشت تکراری. بازبینی و migration اصلاحی در حال تهیه است.

باقی‌مانده: تست‌های منفی یافته‌های بالا و رفع آن‌ها؛ اثبات هم‌زمانی و۱۰۰۰رویداد؛ DOWN برای تمام تغییرات و UP/DOWN/UP؛ feature probe و fallback صحیح کلاینت؛ مسیر اصلاح/ابطال/ذخیره خرید زیر ENFORCE؛ پوشش منبع‌به‌منبع و برچسب صادقانه پوشش؛ گزارش shadow؛ بسته rollout/backup/rollback برای G1؛ CI تازه. آزمون واقعی JWT/PostgREST و Production پذیرش نشده‌اند.

هیچ نصب یا تأییدی از مالک اکنون لازم نیست. G1 فقط پس از آماده‌شدن بسته قابل بازبینی و اثبات کامل درخواست می‌شود. مالک در ۲۰۲۶/۱۱/۰۳ ادامه فازهای بعد را تأیید کرده؛ آغاز آن‌ها تابع گیت مرحله قبل است. [نقشه راه جاری](../ROADMAP_CURRENT.md).
