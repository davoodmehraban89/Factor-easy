# جلوگیری از دورزدن کنترل نسخهٔ سند با مقدار خالی

وضعیت: اصلاح نامزد WP1؛ نصب عملیاتی نشده است.

مقایسهٔ SQL با `<> NULL` نتیجهٔ قطعی درست/غلط نمی‌دهد. بنابراین چهار مسیر ویرایش پیش‌نویس، حذف پیش‌نویس، قطعی‌کردن و برگشت سند، با دریافت نسخهٔ خالی کنترل تعارض را رد می‌کردند. هر چهار نقص روی زنجیرهٔ قبل از اصلاح بازتولید شد.

تغییر افزایشی `20261104214503_wp1_null_revision_guards.sql` فقط چهار مقایسه را به `IS DISTINCT FROM` تبدیل می‌کند. قفل سطر، کنترل مجوز، ترتیب عملیات و قرارداد تکرار درخواست عوض نشده‌اند. درخواست تکراریِ مجاز که قبلاً کامل شده، همچنان بدون تغییر داده نتیجهٔ قبلی را می‌گیرد؛ مقدار خالی دیگر اجازهٔ یک تغییر جدید را نمی‌دهد.

## شواهد

- ۱۶ حالت منفی: نسخهٔ خالی، صفر، منفی و نادرست برای هر چهار عملیات؛ همگی با خطای تعارض رد و رکوردها بدون تغییر باقی می‌مانند.
- ویرایش، حذف، ثبت قطعی و برگشت با نسخهٔ درست موفق‌اند؛ تکرار قطعی‌کردن و برگشت بدون تغییر رکوردها موفق است.
- چرخهٔ UP/DOWN/UP، تعریف و مجوز دقیق چهار تابع را بررسی می‌کند. تنها تفاوت مجاز در UP همان چهار مقایسه است؛ DOWN تعریف قبلی را دقیقاً برمی‌گرداند.
- سه سند قطعی، شش ردیف، ممیزی و شمارنده‌ها در رفت‌وبرگشت بدون تغییر می‌مانند.
- [شواهد ماشینی](evidence/null-revision/result.json)، اجرا: `node scripts/wp1-null-revision-cycle.mjs`.

این آزمون در PostgreSQL ایزوله و نقش authenticated اجرا شده؛ تأیید HTTP/JWT واقعی، تطبیق ساختار کامل Production یا بازبینی مستقل SQL نیست. کنترل‌های CI نسخهٔ یکپارچه و پذیرش کل WP1 جداگانه لازم‌اند.
