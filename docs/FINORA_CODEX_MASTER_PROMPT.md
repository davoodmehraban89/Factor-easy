# پرامپت اجرایی فینورا — دفتر ضدگلوله و تجربهٔ حسابدار

این سند را کامل به Codex بده. هر بار فقط **یک فاز** را اجرا کن، PR جدا بزن، تست همان فاز سبز شود، بعد با اجازهٔ مالک برو فاز بعد. اگر چیزی در این سند با کد زندهٔ `main` نمی‌خواند، کد زنده مقدم است و قبل از نوشتن اختلاف را گزارش کن. حدس نزن.

محصول: فینورا، مخزن `davoodmehraban89/Factor-easy`، شاخهٔ محافظت‌شده `main`، استقرار GitHub Pages، دامنه `factoreasy.ir`، داده و ورود روی Supabase با RLS.
