# قالب برگشت نتیجه به مدیر فینورا

این قالب را همراه فایل یا diff تحویل بده؛ بدون شاهد ادعای اجرا نکن.

```text
شناسهٔ مأموریت:
نسخهٔ مبنا (commit یا هش فایل‌های ضمیمه):
محیط: چت بدون اجرا / محیط کد / مرورگر ایزوله
وضعیت: طرح / patch اجرا نشده / پیاده‌سازی آزموده‌شده / مانع مشخص

خلاصهٔ نتیجه:
فایل‌های تغییرکرده یا فایل گزارش:
diff یا commit و نام branch:

آزمون واقعاً اجراشده:
- فرمان، نسخهٔ کد، خروجی خلاصه، مسیر لاگ
- انتظار و نتیجهٔ واقعی
آزمون‌های اجرا نشده و علت:

یافته‌های مهم: شدت، محل/خط، مراحل بازتولید، اثر، پیشنهاد
فرض‌ها و وابستگی‌ها:
خطر یا تداخل با کار دیگر:
تصمیم موردنیاز از مدیر:
```

برای پژوهش: عنوان منبع، URL رسمی، تاریخ بررسی، ادعای پشتیبانی‌شده و بخش استنباطی را جدا بیاور. برای QA: «سناریو نوشته شد» با «آزمون پاس شد» فرق دارد. فایل پاسخ را مثلاً `FE-B01-result.md` نام‌گذاری کن.
